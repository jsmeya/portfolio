Home Lab

Ongoing

A personal cybersecurity lab built with Kali Linux and Metasploitable 2 in VirtualBox. Documented here as an ongoing series of hands-on sessions covering setup, reconnaissance, exploitation, and beyond.

Disclaimer: This lab is still in its early stages. It runs entirely inside VirtualBox on a single host machine; there's no dedicated network hardware involved. Just Kali and Metasploitable2.

Initialization

  • Installed VirtualBox on the host machine.
  • Created two VMs: Kali Linux as the attacker machine, and Metasploitable2 as the intentionally vulnerable target.
  • Imported each VM's disk image and completed first-boot setup; default credentials on Metasploitable2, standard install/login on Kali.
  • Confirmed both VMs could boot independently before touching networking.

Network Setup

VirtualBox Network Config

By default, VirtualBox VMs are usually given internet access, either via NAT (routes through the host machine) or Bridged mode (the VM appears as its own device on the network).

Alternatively, both VMs were set to Internal Network mode. This creates a private virtual switch that exists only inside VirtualBox and connects only the VMs specifically attached to it. Since MS2 is intentionally SUPER vulnerable, I cannot have it running through my home network...

Both VMs were configured under the same internal network, named labnet.

Checking Initial State

Before assigning anything, I had to check whether either machine already had an IP on the labnet adapter.

msfadmin@metasploitable:~$ ifconfig

eth0 was up but had no inet address, meaning no IP had been assigned yet. I had to run the same check on Kali, which also displayed no address:

kali@kali:~$ ip addr

Assigning Static IPs

With Internal Network mode, there's no DHCP server handing out addresses, so both machines needed manually set IPs set across the 255.255.255.0 subnet.

Metasploitable2:

msfadmin@metasploitable:~$ sudo ifconfig eth0 192.168.50.10 netmask 255.255.255.0

Kali:

kali@kali:~$ sudo ip addr add 192.168.50.11/24 dev eth0

With all of that, here's each machine's address:

Machine IP
Metasploitable2 192.168.50.10
Kali 192.168.50.11

Confirmation

To confirm both machines could actually see each other on labnet:

kali@kali:~$ ping 192.168.50.10

We got a reply from this ping, so we can move forward with some further recon.
