Port Scanner

Ongoing

A simple CLI program for scanning ports on a network using the socket library.
This was built to better understand indirectly how a port scanner like nmap functions behind the scenes.

GitHub Repo

What it does:

The program is a sequential TCP port scanner using Python's socket library. It attempts a connection to every port (1-65535) on a target host. It returns each port as either open or closed based on whether the connection succeeds.

Roughly 9-10 hours for a full range scan (since we have no threading)...

How it works:

  • For each port, the program opens a socket (AF_INET = IPv4, SOCK_STREAM = TCP) and calls connect().
  • A successful connection means a full TCP handshake was completed (SYN, SYN-ACK, ACK) and the specified port is open.
  • Any timeout or connection error means the port is closed.
  • There exists a 0.5s timeout configuration which keeps the scan from stalling on non-responsive ports.

Scan type:

Full connect scan (NOT stealth), meaning no additional privileges required, but it's highly visible in target-side network logs.

Limitations:

No threading, no flags, no extra detection, and no filtered target responses (e.g., closed vs actively refused).

Next steps:

Multithreading, custom port ranges, service/version detection.
